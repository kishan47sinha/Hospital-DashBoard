# 🏥 Hospital Emergency Room Dashboard | Power BI

## 📌 Project Title
**Hospital Emergency Room Dashboard – Interactive Healthcare Analytics using Power BI**

---

## 📖 Short Description

An interactive **Power BI dashboard** designed to analyze Emergency Room (ER) operations and transform raw patient data into meaningful insights. The dashboard provides a comprehensive view of patient flow, wait times, admissions, referrals, demographics, and overall hospital performance through interactive visualizations.

This project showcases how Business Intelligence can be leveraged to support data-driven decision-making in healthcare while demonstrating advanced Power BI dashboard development and visualization techniques.

---

## 🛠️ Tech Stack

- 📊 Power BI Desktop
- 🧮 DAX (Data Analysis Expressions)
- 🔄 Power Query
- 📁 Microsoft Excel / CSV
- 🎨 Custom Dashboard UI Design
- 📈 Data Visualization & Analytics

---

## 📂 Data Source

This project uses a **dummy healthcare dataset** created with the assistance of **ChatGPT** and **Claude AI** for educational and portfolio purposes.

The dataset simulates real-world Emergency Room operations, including patient admissions, referrals, demographics, wait times, satisfaction scores, and treatment details.

---

## ✨ Features & Highlights

- 📊 Interactive KPI Dashboard
- ⏳ Patient Wait Time Analysis
- 😊 Patient Satisfaction Tracking
- 🏥 Department Referral Analysis
- 👨‍⚕️ Patient Demographics (Age, Gender & Race)
- 📅 Monthly & Consolidated Performance Reports
- 📈 Admission vs. Discharge Analysis
- 🕒 Day-wise & Hour-wise Patient Traffic Heatmap
- 📄 Detailed Patient Records Page
- 🔍 Interactive Slicers & Filters
- 🎨 Clean and Modern Healthcare-themed Dashboard Design
